# Kadın — Gizlilik Politikası

**Kadın: Adet Takvimi, Regl Takibi** Android uygulamasının gizlilik politikası.

Bu uygulama hiçbir kişisel veya sağlık verisi **toplamaz, saklamaz veya iletmez**.
AndroidManifest dosyasında `INTERNET` izni bulunmamaktadır; verilerin cihazdan
çıkması teknik olarak mümkün değildir.
